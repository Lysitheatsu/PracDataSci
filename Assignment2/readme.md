### Assignment 2 — Online Retail Customer Segmentation
### Made by Pixy 

#### Overview
This project performs customer segmentation on the UCI Online Retail dataset using RFM (Recency, Frequency, Monetary) analysis. 
The two clustering models are used: K-Means and DBSCAN.

#### Files Included: 
Assignment2.ipynb 
Online Retail.xlsx

#### Requirements
Python 3.8 or above is required.
Install all required libraries by running:
pip install pandas numpy matplotlib seaborn scikit-learn 

#### How to Run:

Assignment2.ipynb & Online Retail.csv need to be in the same folder as the notebook


Open Assignment2.ipynb
Run all cells in order:

Kernel → Restart & Run All

***All outputs and graphs will be displayed inline. Graphs are also saved to the figures/ folder automatically for backup***


#### Notes:
Random state is set to 42 throughout for reproducibility

The "figures/" folder is created automatically when the notebook runs to aid as a backup for the graphs

The dataset file must be named exactly: Online Retail.csv
